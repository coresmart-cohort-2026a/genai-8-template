# Capstone domain

Milestone 1 (Module 1): fill in the five parts below, a few sentences each, and commit. It is not submitted or scored now; the capstone review reads it at the end and compares it with what you built. Module 2 adds the first twenty questions to this file.

## 1. Domain

Which pack, or your own corpus, in one line.

## 2. Users

One named kind of person, and what they need from it.

## 3. Three questions

The first three a user would ask, and where in the corpus the answers live.

## 4. One action

What the agent should be able to do besides answer. Send, file, look up or flag; not "answer questions".

## 5. Architecture sketch

Boxes and arrows: model, retrieval, tools, memory. A photo of paper is fine. Leave at least one box empty and label it as such.

## Decisions

One entry per module from Module 2 on: what you decided about the capstone this module, and why. The capstone assembly guide reads this section first.
